# Fonts

`Geist-Latin-Variable.woff2` and `GeistMono-Latin-Variable.woff2` are the Latin
subset, variable-weight woff2 files served by Google Fonts for Geist (v5) and
Geist Mono (v6), fetched on 2026-11-14. They are embedded in every
report.html so the report works offline.
